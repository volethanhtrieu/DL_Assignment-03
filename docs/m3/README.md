# Assignment 3 — Milestone 3

## Evaluation and Final Reporting

This milestone presents held-out test evaluation, fusion ablation,
inference efficiency, gate analysis and qualitative error analysis
for the five-class CrisisMMD multimodal classification task.

The dataset protocol is filtered_original, with 6,001 training,
986 development and 951 test pairs.
