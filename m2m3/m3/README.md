# Milestone 3 — Evaluation and Analysis Source

This directory contains the original local M3 analysis,
evaluation, visualization and demonstration scripts.

The files were copied from the validated local workspace
without modifying their contents.

## Execution requirements

The scripts currently depend on the sibling M3_Local_Input
workspace for extracted features, checkpoints, raw media
and experiment outputs.

These files are a source snapshot, not yet a standalone
reproducibility package.

The primary experiment pipeline remains in ../experiment.py.

The CLIP and residual-gated scripts represent exploratory
experiments and should not be confused with the reported
primary 15-run evaluation.

Do not publish raw crisis media or private runtime files.
